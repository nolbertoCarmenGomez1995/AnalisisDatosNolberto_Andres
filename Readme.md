# Evidencia de Aprendizaje 2: Automatización y DevOps en Web Scraping

- **Estudiantes:** Nolberto Carmen Gómez y Andrés David Mesa
- **Grupo:** 19
- **Institución:** IU Digital de Antioquia
- **Asignatura:** Programación para Análisis de Datos

## Descripción del Proyecto
Este proyecto implementa un motor de extracción de datos web (Web Scraping) en Python combinando tres metodologías: BeautifulSoup4, Selenium WebDriver y Scrapy. Cuenta con un flujo de trabajo DevOps utilizando Git, control de versiones por ramas, Pull Requests y un pipeline de integración continua (CI/CD) configurado con GitHub Actions.
